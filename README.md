# 쇠맛 줄이기 (Less-soemat)

기계가 쓴 티가 나는 한국어 글을, 뜻과 말투는 그대로 두고 사람이 쓴 글처럼 다듬는 프롬프트입니다.

글을 새로 쓰는 프롬프트가 아닙니다. 이미 있는 글에서 번역투, 상투구, 틀에 찍은 듯한 구조, 지나치게 고른 리듬 같은 "쇠맛"을 덜어 내는 데 씁니다. 사실, 수치, 인용, 주장의 세기, 말투의 높낮이는 바꾸지 않습니다.

## 쓰는 법

### 1. 지시문으로 붙여 넣기
[`SKILL.md`](SKILL.md)에서 맨 위 설정 블록(`---` 사이)을 뺀 본문을 대화형 AI의 지시문(시스템 프롬프트)이나 대화 첫머리에 붙여 넣고, 다듬을 글을 함께 보냅니다.

### 2. Claude Code 스킬로 설치하기
```bash
mkdir -p ~/.claude/skills/less-soemat
curl -fsSL https://raw.githubusercontent.com/4n5rud/Less-soemat/main/SKILL.md \
  -o ~/.claude/skills/less-soemat/SKILL.md
```
설치한 뒤 "이 글 쇠맛 줄여 줘"처럼 요청하면 됩니다.

## 구성

| 장 | 내용 |
|---|---|
| 1 | **한국어 문장 원칙 (중심):** 성분과 조사, 어미를 살리고, 서술어로 끝내고, 비유 대신 일반적인 낱말을 쓰고, 엠대시와 가운뎃점, 꺾쇠 괄호, 겹화살괄호를 쓰지 않기 |
| 2 | 절대로 바꾸지 않는 것: 사실, 인용, 핵심 낱말, 주장의 세기, 말투, 장르 |
| 3 | 글을 고치는 원칙: 필요한 곳만, 덜어 내는 쪽으로, 너무 많이 바꾸지 않기 |
| 4 | 걷어 낼 쇠맛 10가지와 고친 예시 |
| 5 | 손대면 안 되는 사람 글의 흔적 |
| 6 | 장르별 허용 범위 |
| 7 | 작업 순서 |
| 8 | 자기 점검 체크리스트 |
